# MRTBattleRoyale Wiki

Source of the MRTBattleRoyale wiki, built with [MkDocs Material](https://squidfunk.github.io/mkdocs-material/)
and published on GitHub Pages automatically at every change.

## Edit a page

Pages are in `docs/` (plain Markdown). Open a page on GitHub, click the pencil icon, edit, then
**Commit changes**: the site is rebuilt and online again in about a minute.

The menu on the left is the `nav:` list in `mkdocs.yml`: add a new page there too.

## Preview on your PC (optional)

```bash
pip install -r requirements.txt
mkdocs serve
```

Then open http://127.0.0.1:8000.
