# MRTBattleRoyale

**A complete Battle Royale minigame for Paper servers**: solo, duo and squad matches with a shrinking zone, skydive deploy, loot chests and airdrops, a gulag for a second chance, knockdowns, events with their own leaderboard, and a setup that is done almost entirely from in-game menus.

[Get it on Modrinth](https://modrinth.com/plugin/mrtbattleroyale){ .md-button .md-button--primary }

## Features at a glance

| | |
|---|---|
| **Modes** | Solo, Duo and Squad, with parties that queue together |
| **Deploy** | Fixed spawns, or a skydive with one or more launch points and an optional map wall to choose the drop point |
| **Zone** | Configurable phases, damage, a moving zone and a particle wall |
| **Loot** | Loot tables, per-player or full chest spawning, refills, a sound near full chests, airdrops |
| **Gulag** | 1v1 duels to get back in, parallel arenas, kits, an anti-AFK rule |
| **Teams** | Knockdown & revive, team colours, teammate glow (with ProtocolLib) |
| **Spectators** | A camera that follows the players still alive |
| **Events** | Registration, event lobby, rotation or random map draw, points, prizes, schedule |
| **Server** | Hub items, arena menu, NPCs and signs, separate BR chats, plugin-managed scoreboards |
| **Progression** | Stats, levels, coins, a cosmetics shop and leaderboards (SQLite or MySQL) |

!!! info "Compatibility"
    Paper **1.21.4 – 1.21.11** and **26.1 / 26.2**, Java 21.
    Optional: PlaceholderAPI, ProtocolLib, Citizens, Multiverse-Core.
